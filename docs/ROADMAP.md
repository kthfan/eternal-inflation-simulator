## A. 大範圍移動視角

**現況限制**
- 物理座標以固定觀測者為原點，所有東西以 `H·距離` 向外流；離原點越遠流得越快。
- 只在原點周圍 `RGEN` 內模擬（成核、退場、`texit`）；攝影機被限制在 `0.9·RGEN` 內。

**規劃**
- **A1 共動座標儲存**：泡泡改存共動位置 `q = x·e^{−H·tn}`。任一共動點 `A` 為參考時，物理位置為 `(q − A)·e^{Ht}`。
  `circleAt(b, t, A)` 多一個參考點參數。這是平直切片德西特時空的平移對稱，物理不變。
- **A2 模擬區域跟著焦點**：成核區、`texit`、退場判斷改以「焦點」（可移動的共動點）為中心；攝影機不再受原點限制。
  離開的區域不再成核（日後回來不會補上離開期間的歷史）。
- **A2' 分區塊世界**（替代方案）：共動空間切成區塊，每個區塊的成核序列由 `(種子, 區塊編號)` 決定；首次造訪時追算。
  回到舊區域歷史一致，但跨區塊的交互與追算成本需要處理。
- **A3 共動視角**（選項）：畫面縮放隨 `e^{−Ht}` 調整，讓空間在畫面上靜止、泡泡原地長大。遊戲中比較好操作。
- **A4 測試**：焦點移動前後同一區域的歸屬一致、可重現性、長距離移動後數值穩定。

## B. 移動泡泡

**現況**：泡泡軌跡由誕生事件解析決定；所有幾何經過 `U.circleAt`（唯一修改點）。

**規劃**
- **B1 軌跡修正**：每個泡泡可有一串「位移事件」，`circleAt` 在解析中心上加上位移（共動座標中的位移會隨膨脹放大，物理上合理）。
  半徑不變（泡壁仍是光錐）。
- **B2 動作紀錄**：`U.act({ t, type, ... })` 在步進邊界套用並記錄在 `U.actions`。相同種子 + 相同動作紀錄 → 相同歷史。
  動作類型例：`nucleate`（指定位置與真空）、`push`（推動泡泡）、`remove`。
- **B3 快取失效**：泡泡移動後，`collideTime` 快取中與它相關的配對、`texit`、退場判斷都要重算。
- **B4 Territory 不需修改**：它只吃圓。這是先前「幾何只有一個來源」設計的回報。
- **B5 測試**：移動後物理與畫面歸屬仍一致、成核合法性、可重現性（含動作紀錄）。

## D. 遊戲版構想：「有自我意識的宇宙」

> 本節整理與使用者的物理討論（2026-10），作為遊戲版與控制版的設計依據。結論：**採用 2b**（以局部泡泡操控暴脹場），**不採用 2a**（調整整個模擬區的 H）。

### D1. 構想

- 玩家是一個有自我意識的口袋宇宙（泡泡）。
- 消耗自身能量移動；撞上真空能**較高**的宇宙可吸收位能差、增加能量；撞上真空能**較低**的宇宙會被奪走能量（地盤）。
- 可以消耗／吸收能量操控周圍的暴脹場（2b：在附近放下較低或較高真空的泡泡）。

### D2. 暴脹速度與「永遠追不上」的區域

- 假真空的真空能固定 → 德西特時空，膨脹**率** `H` 恆定（核心 `E = e^{H(t−tn)}`，`H` 為常數）。
- 退行速度 `v = H·d`：越遠越快；同一物體的距離指數成長，所以它的退行速度隨時間變快。超過 `RH = c/H` 的地方退行超過光速（空間膨脹，不違反相對論）。
- **事件視界**：物理半徑固定為 `RH`。由 `circleAt` 可推得精確條件：
  - 兩個泡壁都以光速擴張時，只有**泡壁間距 < 2·RH** 才會相遇；
  - 不動的一點距離泡壁 < `RH` 才會被吞沒。
  - 只要任何東西都不超光速，`2·RH` 是硬上限。
- 推論：模擬與繪製只需保留玩家周圍「間距 < 2·RH + 餘裕」的範圍，超出者可**永久丟棄**（它們在視界邊緣紅移、凍結、變暗，可用範圍邊緣霧表現）。
  → 待決策 #2 定案為 **A2「模擬區域跟著焦點走」**：在這個半徑下，丟掉的區域本來就永遠回不去，A2 不是近似而是精確。

### D3. 能量：潛熱

- 疇壁被推向真空能較高的一方；被掃過的區域釋放潛熱 `Δε × 掃過面積`，轉成泡壁動能。這就是現有 `Territory` 的 `wall` 規則。
- 膨脹的時空中總能量不守恆（正真空能的體積變大，總真空能就變大），所以遊戲的「能量」定義為**泡壁動能 = 累積的潛熱**（局部量，帳目清楚），不定義為「真空能 × 體積」。
- 「掃過面積」一律以**相對當地哈伯流**計算：背景膨脹把泡泡撐大不產生也不消耗能量。

### D4. 移動：控制膨脹方向（前脹後縮）

設泡壁相對當地空間的法向速度 `v_n(θ) = u·cosθ + w`（`u`：前進速度、`w`：整體向外的速度）。

- 平移 + 縮放 → 圓永遠是圓；背景膨脹也是縮放。**`Territory` 只吃圓，不需要為移動改規則的幾何部分。**
- 泡壁各點不超光速：`|u| + |w| ≤ c`。現有泡泡是 `u = 0, w = c` 的特例（`R0·E + RH·(E−1)` 正是其解）。
- 能量：前方吞入假真空得到 `Δε × 面積`、後方讓出地盤付出 `Δε × 面積`。在均勻假真空中繞一圈積分 `u·cosθ` 抵消 → **移動本身淨收支為零**；收支只來自前後的位能差（順著位能坡「衝浪」）。可另設效率 `η < 1`（泡壁摩擦、再加熱）讓移動有代價。
- **越大越慢**：背景把半徑撐大 `H·r`；要維持大小需 `w = −H·r`，代入上式得
  `u_max = c·(1 − r/RH)`。`r ≥ RH` 時連大小都維持不住 → 被膨脹凍結、失去控制。玩家必須留在哈伯半徑以內才能行動。
- **維持費**：維持物理大小等於持續讓出地盤，功率 `P = 2π·H·Δε·r²`（2D）。不付費 → 被撐大 → 變慢 → 失控。
- 實作：每一步的控制 `(ux, uy, w)` 固定時有解析解（逐段解析，可重現）：
  `c(t) = (c₀ + u/H)·e^{HΔt} − u/H`，`r(t) = (r₀ + w/H)·e^{HΔt} − w/H`。

### D5. 操控暴脹場：為何選 2b、不選 2a

**2a（整個模擬區同時改變 `H(t)`）的問題**
1. 違反因果：影響瞬間傳遍整區；`RH ~ 2·RH` 之間的區域玩家原則上永遠影響不到。
2. 能量量級不合：代價 `≈ Δρ × 整區面積`，遠大於玩家能擁有的能量。
3. 純真空能不能隨時間改變（`ρ̇ = −3H(ρ+p) = 0`），成本公式只能是遊戲約定。
4. 永動機：推高 → 等它暴脹 → 降回，回收 `Δρ·A·e^{2Ht}`；整區推高時沒有「周圍」能吃掉它，漏洞堵不住。
5. 核心中所有「預測未來」的判斷（`texit`、不可逆的 `retire`、`collideTime` 快取、`2·RH` 丟棄範圍）都假設 `H` 永遠不變，全部要改用 `H_min` 保守估計，模擬範圍跟著變大。
6. `H` 壓太低時泡泡連成一片，暴脹會被玩家親手終結。

**2b（局部放泡泡）**
- 「減速」＝在附近放一個**較低**真空能的泡泡（一般的向下穿隧）。
- 「加速」＝放一個**較高**真空能的區域（向上穿隧）。它比周圍高，泡壁被往內推而**收縮**，很快被周圍吃掉；放出的能量歸吃掉它的一方 → 永動機漏洞自然堵住。
- 符合因果、能量自洽；所需的核心能力（手動成核、向上穿隧、收縮泡泡）同時也是「控制版」需要的。

### D6. 收縮泡泡的原理

- 泡壁受兩種力：壓力差（推向真空能較高的一側）、表面張力（永遠向內）。
- 會收縮的情況：①內部真空能比外面高（向上穿隧、被包圍的假真空孤島）；②小於臨界半徑 `r_c = σ/Δε`（被張力壓垮；能存活的泡泡誕生時至少是 `r_c`，即 `R0`）；③玩家主動收縮（花能量）。
- 與背景膨脹的拉鋸：`dr/dt = H·r − c` → `r(t) = RH + (r₀ − RH)·e^{H(t−t₀)}`，也就是
  `r = r₀·E − RH·(E − 1)`（與擴張的 `R0·E + RH·(E − 1)` 對稱）。
  - `r₀ < RH`：在 `(1/H)·ln(RH/(RH − r₀))` 後縮成一點。
  - `r₀ ≥ RH`：永遠縮不掉（這就是永恆暴脹的原理，也和「玩家 `r ≥ RH` 失控」是同一個不等式）。
- 縮完之後：小區域的泡壁在中心對撞，化為輻射；能量很高的大區域理論上從外面看縮成黑洞，從裡面看成為與外界斷開的嬰兒宇宙（Farhi–Guth 等，推測性物理，可當彩蛋）。

### D7. 補充：大擠壓不是收縮的泡泡

- 負真空能仍遠低於假真空 → 泡壁照樣向外擴張；崩塌的是**內部**時空。
- 程式中 `τ = 年齡·√(1−x²)` 是內部世界線的固有時間：內部的居民在同一刻遇到大擠壓；外部座標中奇點由中心向泡壁擴散、逼近卻追不上（相對同時性，與「有沒有人看」無關）。
- 若玩家是負真空能的宇宙：泡壁強（容易贏），但內部從中心開始死亡 —— 可作為「高攻擊、有壽命」的選擇。玩家可控制泡壁後，`τ` 的雙曲面公式不再成立，需另訂規則（例如沿實際軌跡累積內部時間，或直接用年齡計時）。

### D8. 對核心的影響

- **繪製順序**：原規則「真空能高者先畫（子泡泡能量必低於母泡泡）」在向上穿隧時不成立 —— 子泡泡比母泡泡高，照原規則會被畫在母泡泡底下。
  改為以「繪製鍵 = 自己與所有祖先的真空能最小值」排序（一般的家族中就等於自己的真空能，**既有行為完全不變**）；
  當輸家因此畫在贏家之後，輸家要明確讓出贏家那一側（`lYield`）。
- 路線圖 B4「Territory 不需修改」對**移動**成立，對**向上穿隧**不成立。
- 目前所有泡泡以外面的 `H` 擴張（單一 `H`），口袋宇宙內部各自的膨脹率尚未實作（見 C）。2b 的「減速」在核心中只是放下一個泡泡，玩家身上的效果（視界、速度上限）屆時再依所在區域計算。
